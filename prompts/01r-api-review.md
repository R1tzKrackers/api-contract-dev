# API設計レビュー

## 目的
API設計成果物の人間レビューを実施する。

## レビュー対象
- `{{API_SPEC_DIR}}/openapi.yml`
- `{{API_SPEC_DIR}}/endpoints/`

## レビュー観点
1. **完全性**: 必要なエンドポイントが網羅されているか
2. **一貫性**: 命名規則、レスポンス形式が統一されているか
3. **妥当性**: RESTful原則に従っているか
4. **セキュリティ**: 認証・認可が適切に設計されているか
5. **実現可能性**: 実装可能な設計か

## 判定
- **承認**: 次フェーズ（API検証）へ進む
- **差し戻し**: API設計フェーズに戻る

## 指示
レビュー結果を記録し、承認または差し戻しを判定せよ。

---

## 履歴記録（必須）

フェーズ完了時、`.phase-manager-history.yml` に以下を追記せよ：

```yaml
- phase: "01r-api-review"
  status: "complete"  # または "reject"（差し戻しの場合）
  comment: "レビュー結果を1行で"
  target: "01-api-design"  # 差し戻し先（rejectの場合のみ）
  timestamp: 現在時刻を取得して記録
```
